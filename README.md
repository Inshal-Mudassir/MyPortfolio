# Inshal Mudassir — Personal Portfolio

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.

The portfolio showcases my journey as a Computer Science student, developer, and Data Science enthusiast.

---

## ✨ Features

- Modern and professional light-theme design
- Fully responsive layout
- Multi-page portfolio
- Smooth scrolling
- Scroll reveal animations
- Interactive hover effects
- 3D card tilt effects
- Mouse parallax effects
- Animated statistics
- Project category filtering
- Mobile navigation menu
- Scroll progress indicator
- Back-to-top button
- Contact form validation
- Lazy-loaded images
- Reduced-motion accessibility support
- SEO-friendly structure
- Clean and organized code

---

## 📄 Pages

| Page | Description |
|------|-------------|
| Home | Introduction and featured work |
| About | Background, education, journey and goals |
| Skills | Technical skills and learning areas |

| Experience | Learning journey and career direction |
